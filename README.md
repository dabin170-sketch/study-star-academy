# 공부별 아카데미 2.0

강의 자료(PDF·PPTX·DOCX·TXT·Markdown)를 올리면 원문에서 개념을 찾아 **근거와 함께** 정리하고, 플래시카드·백지 복습·모의고사·오답 분석·학습 통계까지 한곳에서 이어서 공부하는 웹 플랫폼입니다.

- 모든 핵심 기능은 **무료**이고, 유료 AI API·결제·유료 DB가 필요 없습니다.
- 자료와 학습 기록은 **사용자 브라우저(IndexedDB)** 에만 저장됩니다. 서버로 문서를 보내지 않습니다.
- 한 번 접속하면 **인터넷 없이도** 개인 학습 기능이 열립니다(PWA).
- 실시간 4인 스터디(친구 광장)만 서버가 필요합니다.

## 2. 로컬에서 실행하기

필요한 것: [Node.js 20 이상](https://nodejs.org) (22 권장)

```bash
npm install            # 처음 한 번
npm run dev            # 웹 앱: http://localhost:5173
```

친구 광장까지 써 보려면 터미널을 하나 더 열어 서버를 켭니다.

```bash
npm run dev:server     # 실시간 서버: http://localhost:3001
```

그리고 `apps/web/.env.example`을 `apps/web/.env`로 복사합니다(안에 `VITE_SERVER_URL=http://localhost:3001`).

### 자주 쓰는 명령

| 명령 | 하는 일 |
|---|---|
| `npm run build` | 서버와 웹을 모두 빌드 |
| `npm run typecheck` | 전체 타입 검사 |
| `npm test` | 단위·통합 테스트(Vitest) |
| `npm run test:e2e` | E2E 테스트(Playwright, 웹 빌드·서버 실행 자동) |
| `npm run preview` | 빌드한 웹을 4173 포트로 미리 보기 |

브라우저를 내려받을 수 없는 환경에서는 설치된 크롬을 지정해 E2E를 돌릴 수 있습니다: `CHROME_PATH=/usr/bin/google-chrome npm run test:e2e`

## 3. 저장소 구조

```text
study-star-academy/
├── apps/
│   ├── web/                 React + TypeScript + Vite 웹 앱(정적 사이트)
│   │   ├── public/          sw.js(오프라인), manifest, 아이콘
│   │   └── src/
│   │       ├── pages/       화면(아카데미 지도, 도서관, 강의실, 온실, 시험의 탑 …)
│   │       ├── features/    자료 가져오기, 도서관, 퀴즈, 아카데미 지도, 이야기 극장(theater/)
│   │       ├── learning/    학습 기록 서비스, 예시 자료, 프로필
│   │       ├── storage/     IndexedDB(Dexie) 스키마, 백업
│   │       ├── realtime/    친구 광장 클라이언트(Socket.IO)
│   │       ├── components/  픽셀 캐릭터·건물, 공통 UI
│   │       └── test/        통합 테스트(fake-indexeddb)
│   └── server/              Fastify + Socket.IO 실시간 서버
│       └── src/  rooms/ security/ app.ts index.ts
├── packages/
│   ├── shared/              공통 타입, 실시간 프로토콜(Zod), 백업 형식·마이그레이션
│   ├── document-parser/     PDF 레이아웃·PPTX·DOCX·TXT·MD 구조 추출(순수 함수)
│   ├── learning-engine/     개념 추출, FSRS, 문항 생성, 채점, 백지 복습, 숙련도·추천, 보상, 이야기 생성·검증·컷 구성(story/)
│   └── animation-engine/    캐릭터 관절 리그, 동작·표정, 캐스트, 카메라(순수 함수)
├── tests/e2e/               Playwright 시나리오 + PDF 예제
├── docs/                    배포·운영·오류 해결·데이터 문서
├── render.yaml              Render Blueprint(정적 사이트 + 서버)
└── .github/workflows/ci.yml 자동 테스트
```

의존 방향: `shared ← document-parser`, `shared ← learning-engine ← web`, `shared ← animation-engine ← web`, `shared ← server` (순환 없음)

## 4. Render 배포(무료)

자세한 단계는 [docs/DEPLOY.md](docs/DEPLOY.md), 무료 한도·백업은 [docs/OPERATIONS.md](docs/OPERATIONS.md), 오류 해결은 [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md), 데이터 구조·알고리즘은 [docs/DATA_AND_ALGORITHMS.md](docs/DATA_AND_ALGORITHMS.md)에 있습니다. 요약:

1. 이 폴더를 GitHub 저장소로 올립니다.
2. Render 대시보드 → **New → Blueprint** → 저장소 선택 → `render.yaml`을 읽어 두 서비스를 만듭니다.
3. 서버(`study-star-server`)의 `ALLOWED_ORIGINS`에 정적 사이트 주소를, 정적 사이트(`study-star-web`)의 `VITE_SERVER_URL`에 서버 주소를 넣고 다시 배포합니다.
4. 이후 `main`에 푸시하면 GitHub Actions 검사가 통과한 뒤 자동 배포됩니다.

## 6. 알려진 한계

- **개념 추출은 규칙 기반**입니다. “~란 ~이다”, “~을 말한다”, “용어: 설명”, “~의 유형에는 ~이 있다” 같은 문장 형태를 찾습니다. 문장 구조가 특이하면 놓칠 수 있으니 원본 읽기에서 ‘+ 개념’으로 직접 추가해 주세요. 대신 문서에 없는 문장을 만들지 않습니다.
- **PDF 줄바꿈**: 글자 단위로 줄을 바꾼 PDF는 낱말 중간 띄어쓰기를 규칙으로 고치지만 일부(예: “있도 록”)가 남을 수 있습니다. 개념 판정에는 영향이 적도록 보정했습니다.
- **스캔 PDF·손글씨**는 글자를 읽지 못합니다(OCR 개발 예정). 해당 쪽은 ‘확인 필요’로 표시합니다.
- **서술형·백지 복습 자동 판정은 키워드 비교**입니다. 뜻의 정확성은 사용자가 원문과 대조해 판정합니다.
- **실시간 방은 서버 메모리에만** 있습니다. 무료 서버가 재시작되면 방이 사라지고, 화면에서 새 방 만들기를 안내합니다.
- 데이터는 브라우저에만 있으므로 **기기 간 자동 동기화는 없습니다**. 백업 파일로 옮겨 주세요.
- **이야기 극장은 무료 템플릿 모드**입니다. 사건·오해·시도·단서·이해·해결 같은 정해진 뼈대에 개념 원문을 끼워 넣기 때문에 이야기 흐름이 비슷하게 느껴질 수 있습니다. 대신 개념 설명 대사는 원문 그대로이고 근거가 붙습니다. 대사는 편집기에서 자유롭게 고칠 수 있습니다(원문 대사를 고치면 경고 표시).
- 음성은 브라우저 내장 음성 합성을 씁니다. 기기에 한국어 음성이 없으면 자동으로 자막 모드가 됩니다.

## 7. 후속 개선 계획

1. 연결형·순서 배열형·사례형 전용 문항과 기억 카드 배틀·분류 퍼즐 게임
2. 로컬 OCR(tesseract.js, 사용자가 켤 때만 내려받기)과 WebLLM 선택 연동(의미 평가·설명 생성, ‘AI 생성’ 표시)
3. 지식 그래프(개념 관계 자동 추출 + 검증 상태)
4. 이야기 극장 확장: 역할극·번갈아 설명하기, 선택형 AI 각색(WebLLM, ‘AI 생성’ 표시와 원문 검증 유지)
5. 문제 세트·카드 덱 공유(만료·취소 가능한 토큰)

라이선스: 코드는 개인 학습용으로 자유롭게 사용·수정할 수 있습니다. 픽셀 글꼴 [Galmuri](https://github.com/quiple/galmuri)는 SIL OFL 1.1을 따릅니다.
