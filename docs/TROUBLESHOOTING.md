# 오류 해결

## 설치·빌드

| 증상 | 원인 | 해결 |
|---|---|---|
| `npm install`에서 엔진 경고·오류 | Node 버전이 낮음 | Node.js 20 이상(22 권장) 설치 후 다시 |
| `npm ci` 실패 “lockfile” | package.json과 package-lock.json 불일치 | 로컬에서 `npm install` 후 두 파일 모두 커밋 |
| Render 웹 빌드에서 `tsc` 오류 | 타입 오류가 있는 코드 푸시 | 로컬에서 `npm run typecheck`로 확인 후 수정 |
| Render에서 `Cannot find module '@academy/shared'` | 루트가 아닌 폴더에서 빌드 | `render.yaml`의 buildCommand가 루트에서 `npm ci`를 하도록 그대로 둠(Root Directory 설정 비우기) |
| E2E가 브라우저를 못 받음 | 네트워크 제한 | `CHROME_PATH=/usr/bin/google-chrome npm run test:e2e` 처럼 설치된 크롬 지정 |

## 화면·학습

| 증상 | 해결 |
|---|---|
| 새로고침하면 404 | 정적 호스팅에 ‘모든 경로 → /index.html’ 규칙이 필요합니다. Render는 `render.yaml`의 routes로 설정됨 |
| “화면을 여는 중 문제가 생겼어요(파일을 받지 못함)” | 새 버전 배포 직후이거나 오프라인입니다. 새로고침하세요. 기록은 지워지지 않습니다 |
| 업데이트가 반영되지 않음 | 서비스 워커가 예전 파일을 쓰는 중입니다. 탭을 모두 닫았다 다시 열거나, 개발자 도구 → Application → Service Workers → Unregister |
| “저장소를 열 수 없어요” | 시크릿 모드나 브라우저 설정이 IndexedDB를 막은 경우입니다. 일반 창에서 여세요 |
| “저장 공간이 부족합니다” | 설정 → 백업 내보내기 후 큰 PDF 자료를 삭제하세요. 개념·기록만 남기려면 백업을 원본 미포함으로 받아 두면 됩니다 |
| PDF에서 개념이 거의 안 나옴 | ① 스캔본이면 글자가 없습니다(경고 표시됨). ② 정의 문장 형태가 특이할 수 있습니다 → 원본 읽기에서 문단의 ‘+ 개념’으로 추가 |
| PDF 글자가 깨지거나 비어 있음 | 글꼴 문제일 수 있습니다. 원본 프로그램에서 ‘PDF로 저장(글꼴 포함)’하거나 인쇄 → PDF 저장으로 다시 만드세요 |
| 두 단 PDF 문장이 섞임 | 자료 화면 상단에 두 단 판단 결과가 표시됩니다. 판단이 틀렸다면 해당 개념을 ‘제외’하고 직접 추가하세요 |
| .hwp / .ppt / .doc 업로드 불가 | 한글: ‘PDF로 저장’. PowerPoint·Word: .pptx/.docx로 다시 저장 |
| 문제가 하나도 안 만들어짐 | ‘확인 필요’ 개념은 문제로 만들지 않습니다. 도서관에서 ‘원문과 맞아요’를 누르거나 직접 고치세요 |

## 친구 광장

| 증상 | 해결 |
|---|---|
| “실시간 서버 주소가 설정되지 않았어요” | 웹 서비스에 `VITE_SERVER_URL`을 넣고 **다시 빌드** |
| 서버 상태가 계속 “확인 중” | 무료 서버가 깨어나는 중(최대 약 1분). 계속 안 되면 서버 `/health`를 직접 열어 보기 |
| 콘솔에 CORS 오류 | 서버 `ALLOWED_ORIGINS`에 웹 주소가 정확히 있는지(https 포함) 확인 |
| “방에 다시 들어갈 수 없어요” | 서버가 재배포·재시작되어 메모리의 방이 사라졌습니다. 새 방을 만들어 코드를 다시 공유하세요 |
| “요청이 너무 많습니다” | 짧은 시간에 입장 시도를 많이 했습니다. 몇 분 뒤 다시 |
| 이 방은 이미 4명 | 최대 4명입니다. 연결이 2분 넘게 끊긴 사람의 자리는 새 사람에게 넘어갑니다 |
